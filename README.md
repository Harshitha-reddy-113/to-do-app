# To-Do App

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript.

## Features

- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Add Date and Time
- Responsive Design

## Technologies Used

- HTML
- CSS
- JavaScript

## Files

```bash
index.html
style.css
script.js
```

## How to Run

1. Download the project
2. Open `index.html` in browser
